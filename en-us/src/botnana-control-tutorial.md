## Getting Started with Botnana Control

By default, the Botnana BN-B3A starts Mapacode's Botnana Control point-to-point axis-control software automatically at boot.

The BN-B3A connects its Type-C (OTG) port to a USB port on the host computer and communicates using RNDIS. Install the RNDIS driver on the host before use. For Windows 10, see [Install the Windows 10 RNDIS Driver](./faq/windows10_rndis.md). Installation on Windows 11 is similar. Linux hosts should already include the required driver.

After installing the driver, open [http://192.168.7.2:3000](http://192.168.7.2:3000) in a browser. The Botnana Control interface appears as shown below.
