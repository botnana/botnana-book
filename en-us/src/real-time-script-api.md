## Introduction

Botnana Control uses a Forth VM in its real-time event loop to meet more complex programming needs. Commands executed in Forth immediately affect the device's behavior.

The address of the file:

[https://botnana.github.io/botnana-book/real-time-script-api.html](https://botnana.github.io/botnana-book/real-time-script-api.html)
